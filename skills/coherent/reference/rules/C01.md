# C01 — Downstream invariant patches

Investigation procedure only. Catalog metadata lives in
[taxonomy.md](../taxonomy.md). Detection: semantic. Record:
`semantic-findings.json`. Shared write-back: [README.md](README.md).

Requires a named source concept (A01) and a sense of which path should own
it (B01).

## What to search for

A rule that belongs at the *source* of a concept, enforced later with special
cases, guards, or mappings.

- The same `if` copied into handlers, jobs, mappers, and UI adapters
  (`if (amount < 0)`, `if (!user.active)`, `if (status === "deleted")`).
- Mappers that silently coerce illegal combinations into a nearby legal one.
- Comments: “just in case”, “shouldn’t happen”, “defensive”.
- New consumers that rediscover the same guard.

Start from the type or factory that creates the value, then list every
downstream check of that property.

## Distinguish a real issue from an intentional difference

- Intentional: a check at an *untrusted* boundary (HTTP, queue, CLI) when the
  domain type already cannot represent the illegal state. The boundary owns
  the contract; that is not a patch.
- Intentional: a narrow adapter that translates an external vendor’s weaker
  model once.
- Real: the source type still allows the illegal state; every consumer
  patches; a missed path still ships.
- Not C01: defensive noise at every layer of an already-enforced contract
  (D02). Not C01: a boolean flag maze (C03) unless the flags exist to paper
  over a missing invariant.

Move correctness upstream. Do not add another downstream guard.

## Evidence to collect

- The invariant in one sentence.
- The source type/factory and every patch site (file + symbol).
- A path that does *not* have the patch (the miss).
- `authoritativeConcept`: the source that should enforce it.
- `deletionOpportunity`: remove the copies after the source owns the rule.
- Existing tests that pin the invariant (or the lack of them).

## Successful “do not merge”

Two similar guards: one is the domain invariant, one is an HTTP 400 for a
malformed payload. They stay distinct. Record the boundary in
`ARCHITECTURE.md` Invariants and Public APIs.

## How to write the result

Append to `.coherent/semantic-findings.json`:

- `identity`: `invariant-patch:<concept>`
- `detectionMode`: `semantic`
- `status`: `confirmed` when the source allows the illegal state and two or
  more consumers patch it

# D01 — Dependency creep

Investigation procedure only. Catalog metadata lives in
[taxonomy.md](../taxonomy.md). Detection: hybrid. Detector emits
`unused-dep:<name>` and `overlap-dep:a+b`. Record: `decisions.json`. Shared
write-back: [README.md](README.md). Comprehensive overlap work waits until
architecture collapse (B02) has exposed real needs. High-confidence unused
packages may be removed earlier.

## What to search for

Mechanical: runtime dependencies with no import; known overlapping families
(lodash/underscore, moment/dayjs/date-fns, axios/got/…).

Also inspect: a heavy package added for a job `fs`, `crypto`, or an existing
library already does; packages used only via leftover generic infrastructure.

## Distinguish a real issue from an intentional difference

- Intentional: CLI/config-only packages (detector lists this caveat).
  `typescript`, `commander`, `ts-morph`, test runners are treated as
  implicit use.
- Real: last real use is gone, or two libraries do the same job.
- Not D01: unused *code* (A08). Remove the code first, then the package.

## Evidence to collect

- `package.json` entry, import search, scripts/config that might reference
  the binary.
- Overlap family members and which API the code actually calls.

## Successful “do not merge”

`commander` and `ts-morph` are different jobs. Dismiss any overlap story
that treats them as a family.

## How to write the result

Confirm unused only after scripts/config are clean. Dismiss implicit or
CLI-only use. Overlap stays `candidate` until you choose one library.
